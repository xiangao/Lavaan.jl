Model Syntax and Operators

Lavaan.jl uses a domain-specific language (DSL) that is identical to R's lavaan. This allows for highly flexible model specification in a clear and human-readable format.

The Core Operators

OperatorMeaningExample

Labeling and Constraints

You can label parameters by prefixing them with a label and *. This is useful for defining indirect effects or applying constraints.

1. Equality Constraints

Label two parameters with the same name to constrain them to be equal:

model = """
  # Constrain factor loadings of x2 and x3 to be the same
  f =~ x1 + L1*x2 + L1*x3
"""

Lavaan.parse_model_string(model)
3-element Vector{Lavaan.ParsedRow}:
 Lavaan.ParsedRow("f", "=~", "x1", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("f", "=~", "x2", nothing, nothing, "L1", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("f", "=~", "x3", nothing, nothing, "L1", -Inf, Inf, 1, "", "", "")

2. Parameter Definitions (:=)

Use labeling to compute new parameters, such as indirect effects in a mediation model:

# Simple mediation: x -> m -> y
model = """
  y ~ b*m + c*x
  m ~ a*x

  # Indirect effect (a * b)
  indirect := a * b

  # Total effect (indirect + direct)
  total := indirect + c
"""

Lavaan.parse_model_string(model)
5-element Vector{Lavaan.ParsedRow}:
 Lavaan.ParsedRow("y", "~", "m", nothing, nothing, "b", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("y", "~", "x", nothing, nothing, "c", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("m", "~", "x", nothing, nothing, "a", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("indirect", ":=", "a * b", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("total", ":=", "indirect + c", nothing, nothing, "", -Inf, Inf, 1, "", "", "")

Residual Variances and Covariances

By default, Lavaan.jl automatically adds residual variances for all endogenous variables. You can explicitly specify them or their covariances using the ~~ operator.

model = """
  visual =~ x1 + x2 + x3

  # Explicitly allow x1 and x2 errors to correlate
  x1 ~~ x2

  # Fix a variance to a specific value
  x3 ~~ 0.5*x3
"""

Lavaan.parse_model_string(model)
5-element Vector{Lavaan.ParsedRow}:
 Lavaan.ParsedRow("visual", "=~", "x1", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("visual", "=~", "x2", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("visual", "=~", "x3", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("x1", "~~", "x2", nothing, nothing, "", -Inf, Inf, 1, "", "", "")
 Lavaan.ParsedRow("x3", "~~", "x3", 0.5, nothing, "", -Inf, Inf, 1, "", "", "")

Latent Growth Curves (growth())

Growth curve models are a special case of SEM where factor loadings are fixed to represent time.

# Linear growth model
model = """
  # Intercept (i) and slope (s) factors
  i =~ 1*t1 + 1*t2 + 1*t3 + 1*t4
  s =~ 0*t1 + 1*t2 + 2*t3 + 3*t4
"""

model
"  # Intercept (i) and slope (s) factors\n  i =~ 1*t1 + 1*t2 + 1*t3 + 1*t4\n  s =~ 0*t1 + 1*t2 + 2*t3 + 3*t4\n"

Multiple Groups

You can specify a grouping variable to perform multi-group SEM:

# Fit the model across different schools
model = """
  visual  =~ x1 + x2 + x3
  textual =~ x4 + x5 + x6
  speed   =~ x7 + x8 + x9
"""

fit = cfa(model, HS; group="school")
parameterEstimates(fit)[1:6, [:lhs, :op, :rhs, :est, :se]]
